# Execution evidence

- `demo-output.txt`: unedited output of `java -cp build/classes oopnemo.app.Main --demo`.
- `test-output.txt`: output of `scripts/test.ps1`.
- `java-version.txt`: local Java runtime version.
- HTML views: presentation of those captured logs; generated by `scripts/build_report.py --prepare`.
- Matching JPEGs: Chrome screenshots of the complete HTML content blocks, used in the report. The pointer is outside the captured area.

The screenshots show actual executed Java results in a browser viewer. They are not screenshots of an IDE or a live native terminal. The logs, source and tests allow the results to be reproduced independently.

The sample entities are demonstration data. No real payment service is connected.
